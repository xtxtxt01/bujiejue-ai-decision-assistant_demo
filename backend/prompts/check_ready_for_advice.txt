根据对话历史，判断是否已经有足够的信息可以给用户提供深度的个性化决策建议。

## 核心理念
我们不是简单给答案，而是帮用户理解自己的决策模式，看清选择背后的真实动机。建议应该基于充分的探索和理解。

## 判断标准（需同时满足以下全部条件）

1. **核心矛盾清晰** — 用户在纠结什么选项/冲突，已经明确表达
2. **利弊已探讨** — 用户表达了各选项的利弊、担心、或优势
3. **真实想法浮现** — 用户的真实情绪、偏好、内心倾向已经表露
4. **深入探索充分** — 至少有 1-2 轮深入探索：
   - 发现了用户的决策模式或认知偏差
   - 指出了价值观冲突或前后矛盾
   - 与用户的历史决策进行了对比
   - 帮助用户看到了自己没注意到的盲区

## 重要原则

### 何时可以给建议
- ✅ **用户主动明确要求**（"你觉得"、"你建议"、"怎么看"）→ 无论第几轮都直接 ready
- ✅ **已有充分探索**（核心矛盾清晰 + 利弊讨论 + 至少1轮深入探索）→ ready
- ✅ **用户自我觉察**（说"我发现我每次..."、"我其实想XX但YY"）→ 这是给建议的好时机

### 何时不要过早给建议
- ❌ **第3-4轮就判断 ready** — 太早，用户还没充分探索自己
- ❌ **只有表面信息** — 用户只说了基本情况，没探索深层动机
- ❌ **模式未识别** — 还没帮用户看到决策模式、认知偏差、或价值观冲突

### 不需要等的条件
- ❌ 不要因为"没问过父母意见"、"没确认具体数字"就判断不够
- ❌ 不要因为"才第5轮"就一定说不够（如果探索已经很深入）
- ✅ 重点是**探索的深度**，不是轮次

## 常见场景判断

### ✅ 可以给建议
```
场景1：用户自我觉察浮现
用户："我发现我每次都是这样，总想找完美的...其实我就是怕失败。你觉得我该怎么办？"
→ ready（已有深入探索 + 主动要求）

场景2：深入探索后矛盾清晰
第1-2轮：了解基本情况
第3-4轮：探索价值观冲突（你说在意自由，但选的都是稳定的）
第5轮：用户开始反思，承认矛盾
→ ready（核心矛盾清晰 + 有深入探索）

场景3：已识别决策模式
AI："你跳槽时也是这样纠结，最后还是选了安全的。这次呢？"
用户："是的，我就是风险厌恶...那这次要不要试试冒险一次？"
→ ready（模式已识别 + 用户主动反思）
```

### ❌ 还不能给建议
```
场景1：才第3轮，信息太浅
用户："我在纠结要不要跳槽"
AI："为什么纠结？"
用户："新公司钱多，但不稳定"
→ not ready（只有表面信息，没探索深层动机）

场景2：没有深入探索

第1-5轮：只在讨论新公司的薪资、通勤、团队等客观因素
但没有探索：用户为什么在意这些？背后的价值观是什么？有没有决策模式？
→ not ready（缺少深入探索）

场景3：用户还在回避核心
用户反复提外部因素（父母看法、朋友建议），但避谈自己真实想法
→ not ready（真实想法未浮现，需要继续探索）
```

## 输出格式
纯 JSON，无其他内容：
```json
{"ready": true}
```
或
```json
{"ready": false, "missing": "还需要了解用户的真实偏好和内心担忧"}
```
