# GDMS 决策风格测评 - 科学平衡版（12题）

## 文档说明

本测评基于 Scott & Bruce (1995) 的 GDMS (General Decision-Making Style) 理论重新设计，采用**完全平衡**的测量方案，确保每个风格的测量机会完全相等，消除原有版本中的测量偏差。

---

## 设计原则

### 1. 理论基础
- **GDMS 理论**：决策风格是个体的习惯性反应模式，包含 5 种相对独立的风格
- **Maximizer-Satisficer 理论**：追求最优 vs 满足即可的决策倾向

### 2. 科学严谨性
- ✅ **完全平衡**：5 种风格各测量 6 次，理论最高分完全相等（6 分）
- ✅ **情景化设计**：所有题目基于真实决策场景，避免自评句式
- ✅ **无社会期望偏差**：每个选项都是中性的，无明显"好"或"坏"
- ✅ **多维度覆盖**：日常、重大、过程、事后等 8 类决策场景

### 3. 数学平衡性
- 10 道题 × 3 选项 = 30 个选项槽位
- 5 个风格各占 6 个槽位
- 采用 C(5,3)=10 的组合论设计，天然完全平衡

## 第一部分：GDMS 决策风格测评（Q1-Q10）

### 五种决策风格

| 风格代码 | 中文名称 | 核心特征 |
|---------|---------|---------|
| **Rational** | 理性分析型 | 系统收集信息、逻辑分析、权衡利弊 |
| **Intuitive** | 直觉感知型 | 依赖直觉、整体感觉、内心确信 |
| **Dependent** | 参考借鉴型 | 寻求他人意见、集体智慧、外部指导 |
| **Avoidant** | 审慎观望型 | 推迟决策、避免选择、等待时机 |
| **Spontaneous** | 果断行动型 | 快速决策、立即行动、不过度思考 |

## 算分逻辑

### GDMS 决策风格算分（Q1-Q10）

#### 1. 累计原始得分

```javascript
const scores = {
  rational: 0,
  intuitive: 0,
  dependent: 0,
  avoidant: 0,
  spontaneous: 0
};

// 用户答题后累计得分
answers.forEach((answerIndex, questionIndex) => {
  const option = GDMS_QUESTIONS[questionIndex].options[answerIndex];
  scores[option.style] += 1;
});
```

**得分范围**：每个风格 0-6 分

#### 2. 判定主风格

**重要说明**：本系统不使用"平衡型"分类。所有用户都会被归到某个具体的风格（单一或组合），确保后续 prompt 策略有明确的应用对象。

```javascript
// 按得分排序
const sorted = Object.entries(scores).sort((a, b) => b[1] - a[1]);
const highest = sorted[0][1];      // 最高分
const secondHighest = sorted[1][1]; // 第二高分
const gap = highest - secondHighest; // 差距

// 判定规则（三级）

// 规则 1：组合型（两个风格都强且接近）
if (highest >= 3 && secondHighest >= 3 && gap <= 1) {
  return `${sorted[0][0]}_${sorted[1][0]}`;  // 例如：'rational_intuitive'
}

// 规则 2：强单一主导（最高分明显领先）
if (highest >= 4) {
  return sorted[0][0];  // 例如：'rational'
}

// 规则 3：弱主导兜底（所有其他情况）
// 即使最高分较低，也归到最高分的风格
// 因为不支持"平衡型"，所有用户必须有明确归属
return sorted[0][0];
```

#### 3. 判定优先级说明

由于不支持平衡型，判定逻辑简化为**两个层次**：

| 优先级 | 条件 | 输出 | 占比预估 |
|--------|------|------|---------|
| **第一优先**：组合型 | 最高 ≥3 且 第二 ≥3 且 差距 ≤1 | `style1_style2` | ~25-35% |
| **第二优先**：单一主导 | 其他所有情况 | `style1`（最高分风格） | ~65-75% |

**为什么先判断组合型？**

如果用户得分是 `R=4, I=3.5, D=2, A=0.5, S=0`：
- 最高分 R=4 满足"≥4"，但
- I=3.5 也很高，差距只有 0.5
- 应该判定为**组合型**而非单一型

所以**先判断组合**，再判断单一。

### Maximizer vs Satisficer 算分（Q11-Q12）

```javascript
const counts = { maximizer: 0, satisficer: 0, mixed: 0 };

// Q11 和 Q12 的选择
[answer_q11, answer_q12].forEach(answer => {
  counts[answer.tendency] += 1;
});

// 判定
if (counts.maximizer > counts.satisficer) {
  return 'maximizer';      // 追求最优型
}
else if (counts.satisficer > counts.maximizer) {
  return 'satisficer';     // 满足即可型
}
else {
  return 'mixed';          // 灵活平衡型
}
```

## 判定规则的心理学依据

### 主导阈值（≥4 分）
- 4/6 = 66.7%，意味着用户在该风格出现的 6 次机会中，选择了至少 4 次
- 心理测量学中，≥66% 的一致性可视为"强偏好"

### 组合差距（≤1 分）
- 差距 ≤1 意味着两个风格的选择频率接近
- 例如 4:3 的比例（57% vs 43%），表示两种风格都显著存在

### 平衡阈值（<3 分）
- 3/6 = 50%，意味着用户没有在任何风格上表现出多数偏好
- 决策方式更灵活，根据情境调整

## 边界案例处理

### 案例 1：两个风格并列最高

**得分**：Rational: 4, Intuitive: 4, Dependent: 1, Avoidant: 1, Spontaneous: 0

**处理**：
```javascript
// 两个并列最高都是 4，差距 = 0
// 满足组合条件（都 ≥3 且 差距 ≤1）
return `rational_intuitive`;  // 组合型
```

**说明**：并列情况下，按预定义优先级排序（rational > intuitive > dependent > spontaneous > avoidant）

---

### 案例 2：三个风格得分接近

**得分**：Rational: 3, Intuitive: 3, Dependent: 3, Avoidant: 0, Spontaneous: 1

**处理**：
```javascript
// 最高分 3，第二高分也是 3，差距 = 0
// 满足组合条件
// 但有 3 个风格并列，只取前两个
return `rational_intuitive`;  // 组合型（取优先级最高的两个）
```

---

### 案例 3：完全均匀分布

**得分**：Rational: 2, Intuitive: 2, Dependent: 2, Avoidant: 2, Spontaneous: 2

// 所有风格并列，最高分 = 2

// 不满足强单一条件（2 < 4）
// 触发兜底规则：取最高分风格（按优先级）
return `rational`;  // 单一型（弱主导）

**说明**：虽然用户没有明显偏好，但系统会强制归到某个风格，确保有明确的 prompt 策略可用。

### 风格优先级排序

当多个风格得分相同时，按以下优先级排序：

```javascript
const STYLE_PRIORITY = {
  'rational': 1,      // 最高优先级
  'intuitive': 2,
  'dependent': 3,
  'spontaneous': 4,
  'avoidant': 5       // 最低优先级
};
```

**理由**：
- Rational 和 Intuitive 是最核心的两种风格（理性 vs 感性），优先级最高
- Avoidant 通常是负面特征（回避决策），优先级最低
- 这样可以确保并列时选择更"积极"的风格

## 判定规则的心理学依据

### 主导阈值提升（≥3 → ≥4 分）

**旧版本（8题，最高6.5分）**：
- ≥3 分作为主导阈值 → 3/6.5 ≈ 46% 的一致性

**新版本（10题，最高6分）**：
- ≥4 分作为强主导阈值 → 4/6 ≈ 67% 的一致性

**心理测量学标准**：
- 一致性 ≥60% 可视为"强偏好"
- 一致性 40-60% 为"中等偏好"

新版本采用更高的阈值，确保"强单一主导"的用户真正具有明显的风格特征。

---

### 组合差距（≤1 分）

差距 ≤1 意味着两个风格的选择频率接近：
- R=4, I=3（差距1） → 57% vs 43%
- R=4, I=3.5（差距0.5） → 53% vs 47%

**心理学意义**：两种风格都显著存在，用户在不同场景下灵活切换。

---

### 组合型优先判定的原因

**为什么先判断组合型，再判断单一型？**

示例：用户得分 `R=4, I=3.5, D=2, A=0.5, S=0`

- **如果先判断单一**：R=4 ≥4 → 判定为单一 Rational（✗ 忽略了 I=3.5）
- **如果先判断组合**：R≥3 且 I≥3 且 差距0.5≤1 → 判定为 Rational_Intuitive（✓ 更准确）

**结论**：组合型是更精细的分类，应该优先判定。

---

### 为什么不使用"平衡型"？

#### 1. Prompt 策略缺失
- 每种风格都有对应的个性化策略（personality_prompts.py 中的 GDMS_PROMPTS）
- 如果判定为"平衡型"，没有明确的策略可用
- 必须设计一个通用的"平衡型"策略，但这与个性化理念矛盾

#### 2. 心理学理论支持
- GDMS 理论认为，决策风格是"习惯性反应模式"
- 即使得分接近，用户在实际决策中仍会有轻微偏好
- 强制归类可以帮助用户识别自己的"默认模式"

#### 3. 用户体验考虑
- **模糊的标签**："你是平衡型"听起来模糊，缺乏指导意义
- **具体的标签**："你偏向理性型"更具体，更有操作价值
- 用户更希望知道"我倾向于怎么做"，而不是"我什么都可以"

#### 4. 实际概率
- 10道题，用户完全均匀分布（每个风格恰好2分）的概率 < 5%
- 大多数用户会有明显偏好，强制归类的影响很小
- 即使是"弱主导"（最高分2-3分），也能提供有价值的自我认知

#### 5. 系统简化
- 不支持平衡型 → 判定逻辑更简单、健壮
- 所有用户都有明确归属 → 后续 Prompt 拼接不会出错
- 减少一种边界情况 → 降低维护成本

// 1. 浮点容差比较
function isEqual(a, b, epsilon = 0.01) {
  return Math.abs(a - b) < epsilon;

// 2. 稳定排序（处理并列）
function sortScores(scores) {
  const priority = ['rational', 'intuitive', 'dependent', 'spontaneous', 'avoidant'];
  return Object.entries(scores).sort((a, b) => {
    if (b[1] !== a[1]) return b[1] - a[1];  // 按分数降序
    return priority.indexOf(a[0]) - priority.indexOf(b[0]);  // 并列时按优先级
  });
}
