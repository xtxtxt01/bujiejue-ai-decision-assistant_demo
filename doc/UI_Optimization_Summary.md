## 🎨 样式优化（高级简洁风）

### 1. 题目文本
```css
.form-label {
  font-size: 15px;           /* 14px → 15px，更清晰 */
  font-weight: 500;
  color: var(--text-primary); /* 深色，更有层次 */
  margin-bottom: 16px;        /* 增加间距 */
  line-height: 1.5;           /* 提升可读性 */
  letter-spacing: -0.01em;    /* 微调字距，更精致 */
}
```

### 2. 选项按钮（核心优化）
```css
.tag {
  padding: 14px 18px;                    /* 更宽松舒适 */
  font-size: 14px;                       /* 13px → 14px */
  line-height: 1.6;                      /* 多行文本更美观 */
  border: 1.5px solid var(--border);     /* 边框加粗 */
  color: var(--text-primary);            /* 深色文本 */
  transition: cubic-bezier(0.4, 0, 0.2, 1); /* 流畅动画 */
  letter-spacing: -0.01em;               /* 精致字距 */
}

.tag:hover {
  border-color: var(--accent);
  background: var(--accent-light);       /* 浅蓝背景 */
  transform: translateY(-1px);           /* 微抬升效果 */
  box-shadow: 0 2px 8px rgba(74, 125, 255, 0.1); /* 阴影 */
}

.tag.active {
  background: var(--accent);             /* 纯蓝背景 */
  color: white;                          /* 白色文字 */
  box-shadow: 0 2px 12px rgba(74, 125, 255, 0.2); /* 更强阴影 */
}
```

### 3. 题目间距
```css
.form-group {
  margin-bottom: 32px;  /* 24px → 32px，更透气 */
}
```

## ✨ 设计理念

### 高级感来源
1. **细节把控**
   - 边框从 1px 加粗到 1.5px
   - 字距 letter-spacing: -0.01em（Apple 风格）
   - 动画使用 cubic-bezier 缓动函数

2. **层次感**
   - 未选中：浅灰边框 + 深色文字
   - Hover：蓝色边框 + 浅蓝背景 + 轻微抬升
   - 选中：纯蓝背景 + 白色文字 + 强阴影

3. **留白与呼吸感**
   - 选项内边距增加（10px → 14px）
   - 题目间距增加（24px → 32px）
   - 题目与选项间距增加（10px → 16px）

### 避免花哨
- ❌ 没有渐变色
- ❌ 没有多余图标
- ❌ 没有动效过度
- ✅ 纯色 + 微动效 + 精致间距
