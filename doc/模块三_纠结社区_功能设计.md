# 模块三：纠结社区功能设计文档

> 不纠结 · AI 个性化决策助手 | 模块设计文档 3/3

---

## 一、模块定位

**社区不是社交平台，是"决策经验库"。**

**核心价值**：让用户看到"跟我情况相似的人，面对同样的纠结，最后怎么选的、结果怎么样"。

**解决的需求**：纠结时用户最想知道的不是"我应该怎么选"，而是"跟我情况一样的人都怎么选的"。现状是用户会去小红书、知乎、OfferShow 找类似案例——这说明是真需求。我们的优势是能基于用户画像做**精准推荐**，并在对话中**无缝插入**参考信息。

**价值定位升华**：有证据辅佐的同时，也让用户不再孤单。

---

## 二、与社交平台的本质区别

| 维度 | 社交平台 | 本产品社区 |
|------|---------|-----------|
| 内容形态 | 自由发帖、图文视频 | 结构化脱敏卡片 |
| 互动方式 | 评论、私信、关注 | 仅轻量"我也是"共鸣标记 |
| 排序逻辑 | 按热度/时间 | 按"跟你相似度"推荐 |
| 准入门槛 | 人人可发 | 邀请制 + 有结果验证才进推荐池 |
| 内容目的 | 表达、社交 | 为决策提供参考证据 |

**关键约束**：只支持轻量化点赞/共鸣，**不做评论区、不做私信、不做 1 对 1 匹配聊天**——避免变成社交平台或聊天室。

## 三、内容来源：用户如何成为贡献者

### 贡献流程

```
卡片关闭 3 个月后
  → 系统邀请补充事后回顾："3个月前你决定接那个offer了，现在回头看怎么样？"
  → 用户填写复盘
  → 系统询问是否愿意脱敏分享
  → 用户预览脱敏版并可编辑
  → 确认发布
```

### 脱敏规则

- **自动去除**：个人身份信息（公司名、人名、具体薪资等）
- **保留**：决策结构（背景、核心矛盾、纠结时长、最终选择、决策转折点、事后回顾）
- **用户可控**：预览脱敏版并编辑后再确认发布

### 进入推荐池的硬性条件

**案例必须包含"事后回顾"——没有结果验证的案例不进入推荐池。** 这是社区价值的核心保证：用户看到的是"别人选了之后真实的结果"，而非空泛的选择。

## 四、案例结构

每个社区案例是一张结构化脱敏卡片：

```
┌─────────────────────────────────────────┐
│ 纠结类型：跳槽 vs 留下                    │
│ 背景：互联网 3 年 | 薪资+30% | 加班多      │
│ 核心矛盾：成长空间 vs 稳定                │
│ 纠结时长：21 天                           │
│ 最终选择：跳槽                            │
│ 决策转折点：想通了"适应期不舒服"和         │
│            "一直待着不成长"哪个更后悔       │
│ 事后回顾（3个月后）：不后悔（8/10分）      │
│ 相似人数：🙋 327 人也纠结过这个           │
└─────────────────────────────────────────┘
```

字段：纠结类型、脱敏背景、核心矛盾、纠结时长、最终决策、决策原因/转折点、事后回顾（含结果验证评分）。

## 五、核心功能

### 5.1 用户主动浏览（按分类标签自行浏览）

- 按纠结类型分类展示（换工作 / 考研 / 关系 / 消费 / 创业等）
- 支持按标签筛选查询"跟我情况一样的人最后怎么选的"
- 可收藏案例到个人参考库
- 轻量互动："我也是"共鸣标记

### 5.2 个性化推荐（系统主动推荐）

**匹配逻辑**：围绕"对这个决策有参考价值"的因素，而非表面相似度。

| 匹配维度 | 为什么匹配这个 |
|----------|---------------|
| 纠结类型 + 决策阶段 | 同类决策、同一卡点才有参考性 |
| 核心卡点 | 怕的东西一样才有共鸣 |
| 决策风格 | 同类型的人应对方式更可借鉴 |
| 人生阶段 | 约束条件相似 |

**不匹配**的维度：行业、公司、薪资——这些是表面信息，不影响"纠结的本质"。

**推荐示例**：

```
你的价值观是"成长>稳定"，这里有 3 个同样价值观的人的选择：
- 2 人选了跳槽，1 人选了留下换组
- 跳槽的 2 人事后都说不后悔
```

按相关度推荐，非按热度排序。两面都给（既给"换了发现也 OK"的案例，也给"没换也过得不错"的案例）。

### 5.3 对话中无缝引入（RAG 整合）

**最关键的差异化用法**：社区案例不是独立浏览，而是作为对话素材，在决策僵局时被系统主动调用，推进决策。

**触发时机**（系统判断用户进入决策僵局）：
- 用户连续 2 轮表达犹豫但无新信息输入
- 历史模式显示用户在这个环节容易卡住
- 个性化建议已给出但用户仍未行动

**引入方式**：

```
AI: "你现在的纠结点主要是怕适应期。社区里有几个跟你情况很像的人——
     也是工作 2-3 年、纠结换工作、拿到 offer 后犹豫的。
     他们后来的选择和结果我可以给你看看，要不要参考一下？"
```

看完案例后，系统主动关联回用户的具体情况，把案例作为推进 UC-01 决策对话的素材，而不是看完就结束。

## 六、目标场景（UC-02）

**看相似的人怎么选的**（接 UC-01，用户拿到 offer 后第 3 天，连续两轮无法推进，进入决策僵局）

```
1. 触发推荐：系统识别僵局信号，自然引入社区案例
2. 个性化匹配：基于纠结类型/核心卡点/决策风格/人生阶段匹配
3. 展示案例：聚焦决策过程和结果验证（必须有事后回顾）
4. 整合回对话：将案例关联回用户具体情况，推进决策
```

### 备选流程

| 场景 | 系统行为 |
|------|---------|
| 用户主动浏览（非僵局触发） | 按类型分类展示，不强制关联回对话 |
| 高相似案例不足 3 个 | 放宽匹配（如不限决策风格），标注"部分相似" |
| 用户说"他的情况跟我不一样" | 追问差异点，调整匹配维度重新推荐 |

### 异常流程

| 场景 | 系统行为 |
|------|---------|
| 冷启动期无同类案例 | 不推荐社区，继续个性化对话 |
| 用户负面对比（"他成功了我肯定不行"） | 识别心态，回应："每个人情况不同，这只是参考。你觉得你跟他最大的区别是什么？" |

## 七、社区 × 记忆系统

社区推荐基于用户的**核心记忆**（价值观、人生阶段、决策风格）实现精准匹配：

- 纠结"换工作怕不稳定" → 推"最后换了发现也 OK"和"没换也过得不错"两类案例
- 价值观排序"成长>稳定" → 优先推同样价值观的人的经历
- 决策风格"回避型" → 推同为回避型但最终迈出一步的人的故事

---

## 八、审核策略

**原则：结构化内容比自由文本好审核。**

- 分享内容是结构化卡片（不是自由输入），大部分字段是选择题或短文本
- AI 预审核 + 人工抽检
- 初期邀请制（需积累一定记录量才能解锁分享权限）
- 举报机制 + 快速下架

**成本控制**：因为内容是结构化的（非长文/图片/视频），审核量远低于传统 UGC 社区。

## 九、MVP 范围

### 做（V1）

- 匿名分享（用户选择性分享，系统自动脱敏）
- 按类型/标签浏览
- 收藏到个人参考库
- "我也是"共鸣标记
- 基于画像的个性化推荐
- 对话中 RAG 引入案例

### 不做（V1）

- 1 对 1 匹配聊天（算法复杂，体验不好就是灾难）
- 实时讨论 / 评论区（会变成聊天室）
- 关注 / 私信等社交关系链

- **上游（模块二）**：卡片关闭 + 事后复盘 → 脱敏 → 成为社区案例来源
