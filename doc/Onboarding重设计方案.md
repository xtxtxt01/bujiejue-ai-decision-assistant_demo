# 「不纠结」Onboarding 重设计方案

## 一、理论基础

### 1. GDMS 决策风格模型（Scott & Bruce, 1995）

学术界最广泛使用的决策风格框架，将个人决策模式分为 5 种：

| 风格 | 英文 | 核心特征 | 典型表现 |
|------|------|----------|----------|
| 理性型 | Rational | 逻辑驱动，系统分析 | 收集信息、列利弊清单、按步骤评估 |
| 直觉型 | Intuitive | 直觉驱动，整体感知 | 凭感觉、相信第六感、难以解释原因 |
| 依赖型 | Dependent | 他人导向，寻求指导 | 先问朋友/家人、参考多方意见、缺乏独立判断信心 |
| 回避型 | Avoidant | 拖延回避，推迟责任 | 能不决定就不决定、维持现状、将责任转移给他人 |
| 冲动型 | Spontaneous | 速度优先，即时行动 | 凭一时冲动、很快做出决定、不愿深思 |

**在不纠结中的应用**: 通过情景题推断用户主导风格，而非让用户自我贴标签。系统根据风格调整辅助策略——对理性型提供结构化框架，对直觉型帮助验证直觉，对回避型温和推动。

### 2. 最大化者 vs 满足者（Schwartz, 2002）

Barry Schwartz 的"选择悖论"理论中的关键维度：

- **最大化者 (Maximizer)**: 追求最优解，穷尽所有选项后才做决定。选择后容易后悔，常想"会不会有更好的"
- **满足者 (Satisficer)**: 设定"足够好"的标准，达到即可。选择后满意度更高，不纠结于未选的选项

**在不纠结中的应用**: 这是一个独立于 GDMS 的正交维度。最大化者是我们的核心用户群（最容易"纠结"的人），系统可以帮助他们设定"足够好"的标准。

### 3. Schwartz 价值观理论（Schwartz, 1992）

10 种基本人类价值取向，分为 4 个高阶类别：

| 高阶类别 | 包含的价值 | 核心动机 |
|----------|-----------|----------|
| 开放性 (Openness to Change) | 自主、刺激 | 追求独立思考与新鲜体验 |
| 自我提升 (Self-Enhancement) | 成就、权力、享乐 | 追求个人成功与满足 |
| 保守性 (Conservation) | 安全、遵从、传统 | 追求稳定、秩序与规范 |
| 自我超越 (Self-Transcendence) | 仁慈、普世 | 关注他人与社会福祉 |

**在不纠结中的应用**: 用用户友好的语言呈现，让用户选择 3-5 个最重要的价值关键词。决策时系统可以提醒"这个选择是否符合你的核心价值"。

## 二、新 Onboarding 流程设计

### 总览（6 步）

```
Step 0: 创建账号（用户名、密码、昵称）
Step 1: 决策模式（GDMS 情景推断 + 最大化倾向）
Step 2: MBTI（保留，新增"不确定"选项）
Step 3: 关注领域 + 人生阶段
Step 4: 价值排序 + 自我介绍（选填）
Step 5: 主题选择
```

---

### Step 0: 创建账号

保持不变：用户名、密码、昵称。

---

### Step 1: 决策模式（核心改动）

**标题**: "了解你的决策习惯"
**副标题**: "回答几个小场景，帮助我们理解你做决定的方式"

#### Part A: 情景题（8 道，推断 GDMS 风格）

每道题提供 2-3 个选项，用户选最符合自己的。每种风格至少被 2 道题覆盖。

**Q1**: 周末约朋友吃饭，怎么选餐厅？

| 选项 | 映射 |
|------|------|
| A. 打开点评 app 看评分、价格、距离，综合对比后决定 | 理性型 +1 |
| B. 想到哪家就去哪家，感觉对了就行 | 直觉型 +1 |
| C. 发群里问"你们想吃啥"，大家说了算 | 依赖型 +1 |

**Q2**: 网购看中两件外套，价格差不多但风格不同——

| 选项 | 映射 |
|------|------|
| A. 两件都买了再说，不喜欢退掉 | 冲动型 +1 |
| B. 先收藏，过几天再看看还想不想要 | 回避型 +1 |
| C. 搜测评、对比材质面料，选性价比高的 | 理性型 +1 |

**Q3**: 面对一个重要决定（比如换工作），你最先做的是——

| 选项 | 映射 |
|------|------|
| A. 列个清单：现状 pros/cons、新机会 pros/cons，逐条对比 | 理性型 +1 |
| B. 问身边换过工作的人怎么看 | 依赖型 +1 |
| C. 安静地想想内心真正想要什么 | 直觉型 +1 |

**Q4**: 一个决定已经拖了很久没做，最可能是因为——

| 选项 | 映射 |
|------|------|
| A. 每个选项都不完美，找不到最优解 | 回避型 +1 |
| B. 总觉得信息还不够、时机还没到 | 回避型 +1 |
| C. 其实心里有答案，但不敢行动 | 直觉型 +0.5，回避型 +0.5 |

**Q5**: 朋友向你推荐一部电影，你会——

| 选项 | 映射 |
|------|------|
| A. 马上找来看，朋友推荐的一般不会错 | 依赖型 +1 |
| B. 先看看豆瓣评分和影评再决定 | 理性型 +1 |
| C. 收藏了，但可能一直不会看 | 回避型 +1 |

**Q6**: 做决定时，你更相信——

| 选项 | 映射 |
|------|------|
| A. 数据和事实 | 理性型 +1 |
| B. 直觉和感觉 | 直觉型 +1 |
| C. 有经验的人的建议 | 依赖型 +1 |

**Q7**: 超市结账时看到收银台旁的小零食，你会——

| 选项 | 映射 |
|------|------|
| A. 想吃就拿，反正不贵 | 冲动型 +1 |
| B. 想想购物清单里有没有，没有就不买 | 理性型 +1 |
| C. 拿起来又放回去，纠结一会儿最后还是没买 | 回避型 +0.5，理性型 +0.5 |

**Q8**: 关于做决定这件事，你觉得——

| 选项 | 映射 |
|------|------|
| A. 想清楚了就快速行动，不拖延 | 冲动型 +1 |
| B. 能不做决定就不做，维持现状挺好 | 回避型 +1 |
| C. 决定要做，但需要时间好好想 | 理性型 +0.5，直觉型 +0.5 |

#### Part B: 最大化倾向（2 道）

**Q9**: 做了决定之后，你通常会——

| 选项 | 映射 |
|------|------|
| A. 反复想是不是还有更好的选择 | 最大化者 +1 |
| B. 决定了就决定了，往前看 | 满足者 +1 |
| C. 看情况，重要的事会多想，小事不会 | 中间型 +1 |

**Q10**: 选择多的时候（比如点外卖有 50 家餐厅），你会——

| 选项 | 映射 |
|------|------|
| A. 觉得压力很大，害怕选错 | 最大化者 +1 |
| B. 快速筛选出几个"还不错"的，选一个 | 满足者 +1 |
| C. 干脆选以前吃过的，省心 | 满足者 +1 |

#### 风格判定逻辑

1. **GDMS 主风格**：统计 5 种风格（理性/直觉/依赖/回避/冲动）的得分，取最高分为主导风格
   - 如果最高分 ≥ 3 分：单一主导风格
   - 如果有 2 个风格并列最高（且 ≥ 2 分）：组合标记（如"理性-回避型"）
   - 如果所有风格得分都很平均（最高分 ≤ 2）：标记为"平衡型"

2. **最大化倾向**：Q9+Q10 单独计分
   - 最大化者 ≥ 1 分 → maximizer
   - 满足者 ≥ 1 分 → satisficer
   - 都有分 → mixed

3. **前端展示结果**：

```
你的决策模式：理性分析型 · 最大化倾向

【理性分析型】
你喜欢收集充分信息后再做决定，注重逻辑和数据。

【最大化倾向】
你倾向追求最优解，选择后容易想"会不会有更好的"。

「不纠结」会帮你：
• 提供结构化的决策框架
• 在信息充分时提醒你"可以决定了"
• 帮你设定"足够好"的标准，避免过度纠结
```

#### 五种 GDMS 风格的用户呈现

| 内部标签 | 面向用户名称 | 简介 | 系统辅助策略 |
|----------|-------------|------|-------------|
| rational | 理性分析型 | 喜欢搜集信息、对比分析后做决定 | 提供决策框架，适时提醒"信息已够" |
| intuitive | 直觉感知型 | 相信自己的第一感觉和整体判断 | 帮助验证直觉，补充盲点 |
| dependent | 参考借鉴型 | 重视他人意见和集体智慧 | 帮助区分"参考"和"依赖"，增强独立判断力 |
| avoidant | 审慎观望型 | 不急于做决定，倾向多等等看 | 温和推动，拆分大决策为小步骤 |
| spontaneous | 果断行动型 | 速度快，想到就做，不拖泥带水 | 帮助慢下来看看有无遗漏 |

> 注意：面向用户的名称避免负面标签（不叫"回避型"而叫"审慎观望型"，不叫"冲动型"而叫"果断行动型"）

#### 最大化 vs 满足倾向的用户呈现

| 内部标签 | 面向用户名称 | 简介 | 系统辅助策略 |
|----------|-------------|------|-------------|
| maximizer | 追求最优型 | 希望找到最好的答案，选择后容易想"有没有更好的" | 帮助设定"足够好"标准，提醒过度搜索的成本 |
| satisficer | 务实满意型 | 达到标准就满意，不过分纠结未选的选项 | 帮助扩展视野，避免过早满足于次优解 |
| mixed | 灵活权衡型 | 重要决定追求最优，小事满意即可 | 帮助识别"值得最大化的场景"，分配精力 |

> 注意："最大化者"往往是最容易纠结的用户群，系统重点帮助他们认识到"最优解"的机会成本

### Step 2: MBTI

**标题**: "你的 MBTI 类型"
**副标题**: "如果你知道的话，选一个。不确定也没关系"

- 保留 16 种 MBTI 选项
- **新增一个选项**: 🤷 "不确定 / 没测过"
- 选择"不确定"时，后续对话中系统可以通过交互自然推断

---

### Step 3: 关注领域 + 人生阶段

**标题**: "你希望「不纠结」在哪些方面帮你？"

#### 3A: 关注领域（多选，至少选 1 个）

| 选项 | key |
|------|-----|
| 💼 工作与职业发展 | career |
| 💝 感情与人际关系 | relationship |
| 🏠 生活方式选择 | lifestyle |
| 💰 消费与财务决策 | finance |
| 🌱 个人成长与方向 | growth |
| 🎓 学业与升学 | education |

#### 3B: 人生阶段（单选 + 可选填）

**标题**: "你目前的状态是？"

| 选项 | key |
|------|-----|
| 🎒 在读学生 | student |
| 🚀 刚入职场（工作 0-3 年） | early_career |
| 💼 职场中期（工作 3-10 年） | mid_career |
| 🏢 资深职场人 / 管理层 | senior |
| 🏡 自由职业 / 创业中 | freelance |
| 🔄 正在转型 / 找方向 | transition |
| 🌊 间隔期 / 休息调整中 | gap_year |
| 🏠 全职在家（带娃/照顾家人/自己选择） | homemaker |
| 🌱 其他情况 | other |

- 选择"🌱 其他情况"后，可选填一句话简单描述（50 字内）
- 或者所有选项后都加一个可选填写框："补充说明（选填）"，让用户自己定义

---

### Step 4: 价值排序 + 自我介绍

**标题**: "什么对你最重要？"
**副标题**: "选择 3-5 个你最看重的价值，按重要程度排序"

#### 4A: 价值选择与排序

基于 Schwartz 价值观理论简化为用户友好的关键词：

| 价值 | 对应理论 | 说明 |
|------|----------|------|
| 自由自主 | Self-Direction | 按自己的想法生活和做事 |
| 新鲜刺激 | Stimulation | 追求新体验、不喜欢一成不变 |
| 享受生活 | Hedonism | 让自己开心、舒适最重要 |
| 成就认可 | Achievement | 想在领域内做出成绩、被认可 |
| 财富地位 | Power | 追求经济实力和社会地位 |
| 安全稳定 | Security | 稳定的收入、关系和生活节奏 |
| 家庭责任 | Conformity/Tradition | 满足家人期望、遵守承诺 |
| 助人利他 | Benevolence | 帮助身边的人、维护关系 |
| 社会公正 | Universalism | 关心社会公平与环境问题 |
| 健康平衡 | （补充） | 身心健康和工作生活平衡 |

交互方式：先从列表中选择 3-5 个，然后拖拽/上下箭头排序。

#### 4B: 自我介绍（选填）

**标题**: "简单介绍一下自己？"
**副标题**: "选填。了解你更多背景，帮我给出更贴合你的建议"

文本框，最多 200 字。

placeholder 引导示例：
```
比如：90后，坐标上海，互联网行业产品经理，已婚有娃。平时喜欢跑步和看书，性格偏内向，容易想多。
```

**设计意图**：
- 定位是"让系统了解你这个人"，而非某个具体困惑
- 引导方向：年龄段、城市、职业、家庭状况、兴趣爱好、性格特点
- 只给一个自然的例子，不拆成多个子问题，让用户自由选择想透露的程度
- 因为涉及隐私，明确标注"选填"，不填也完全可以跳过
- 采集到的内容存入核心记忆，后续对话中系统可以参考

---

### Step 5: 主题选择

保持现有设计，5 种低饱和主题渐变色。

## 四、设计原则总结

1. **情景化推断 > 自我贴标签**: 用户不需要懂心理学术语，通过日常场景自然表达偏好
2. **正面命名**: 所有风格名称都积极正面（"审慎观望"而非"回避"）
3. **渐进披露**: 从轻松的场景题开始，逐步过渡到需要自省的价值排序
4. **结果即时反馈**: 推断完风格后立刻展示结果，让用户觉得"被理解了"
5. **选填兜底**: MBTI 可不确定、自我介绍可跳过，降低注册门槛
6. **理论有据**: 每个环节都有学术文献支撑（GDMS、Schwartz Values、Maximizer-Satisficer）
