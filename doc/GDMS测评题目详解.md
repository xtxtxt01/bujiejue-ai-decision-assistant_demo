# GDMS 决策风格题目（10道题）

## 概述

- **题目数量**：10 道
  - 前 8 道：GDMS 决策风格测评（5 种风格）
  - 后 2 道：最大化倾向测评（3 种倾向）
- **测评时长**：约 2-3 分钟
- **评分方式**：累计得分制

---

## 第一部分：GDMS 决策风格测评（Q1-Q8）

### 测评的 5 种风格

| 风格 | 英文代码 | 中文名称 | 描述 |
|------|---------|---------|------|
| Rational | rational | 理性分析型 | 喜欢搜集信息、对比分析后做决定 |
| Intuitive | intuitive | 直觉感知型 | 相信自己的第一感觉和整体判断 |
| Dependent | dependent | 参考借鉴型 | 重视他人意见和集体智慧 |
| Avoidant | avoidant | 审慎观望型 | 不急于做决定，倾向多等等看 |
| Spontaneous | spontaneous | 果断行动型 | 速度快，想到就做，不拖泥带水 |

### Q1：周末约朋友吃饭，怎么选餐厅？

**场景类型**：日常生活决策

**选项**：
- A. 打开点评 app 看评分、价格、距离，综合对比后决定
  - **得分**：rational +1
- B. 想到哪家就去哪家，感觉对了就行
  - **得分**：intuitive +1
- C. 发群里问"你们想吃啥"，大家说了算
  - **得分**：dependent +1

**测量维度**：信息收集方式、决策主导性

**场景类型**：消费决策

  - **得分**：rational +1

  - **得分**：spontaneous +1
- C. 先收藏，过几天再看看还想不想要
  - **得分**：avoidant +1

**测量维度**：决策速度、风险承受度

  - **得分**：rational +1
- B. 问身边换过工作的人怎么看
  - **得分**：dependent +1

  - **得分**：intuitive +1

**测量维度**：决策起点、信息来源偏好

**场景类型**：决策拖延

**选项**：
- A. 每个选项都不完美，找不到最优解
  - **得分**：avoidant +1
- B. 总觉得信息还不够、时机还没到
  - **得分**：avoidant +1

**测量维度**：拖延原因、内心冲突

## 第二部分：最大化倾向测评（Q9-Q10）

### 测评的 3 种倾向

| 倾向 | 英文代码 | 中文名称 | 描述 |
|------|---------|---------|------|
| Maximizer | maximizer | 追求最优型 | 追求最佳选择，决策后容易反思是否有更好的 |
| Satisficer | satisficer | 满足即可型 | 追求"足够好"的选择，决策后不过度纠结 |
| Mixed | mixed | 灵活平衡型 | 根据情况调整，重要决策追求最优，小事不纠结 |

---

### Q9：做了决定之后，你通常会——

**场景类型**：决策后反应

**选项**：
- A. 反复想是不是还有更好的选择
  - **倾向**：maximizer
- B. 决定了就决定了，往前看
  - **倾向**：satisficer
- C. 看情况，重要的事会多想，小事不会
  - **倾向**：mixed

**测量维度**：决策后焦虑、后悔倾向

---

### Q10：选择多的时候（比如点外卖有 50 家餐厅），你会——

**场景类型**：选择过载

**选项**：
- A. 觉得压力很大，害怕选错
  - **倾向**：maximizer
- B. 快速筛选出几个"还不错"的，选一个
  - **倾向**：satisficer
- C. 干脆选以前吃过的，省心
  - **倾向**：satisficer

**测量维度**：选择焦虑、决策策略

**注意**：选项 B 和 C 都是 satisficer，但策略不同（快速筛选 vs 经验依赖）

## 算分逻辑

### GDMS 决策风格（Q1-Q8）

#### 1. 累计各风格得分

```javascript
const scores = {
  rational: 0,
  intuitive: 0,
  dependent: 0,
  avoidant: 0,
  spontaneous: 0
};

// 根据用户选择累计得分
answers.forEach((answerIndex, questionIndex) => {
  const option = SCENARIO_QUESTIONS[questionIndex].options[answerIndex];
  Object.entries(option.scores).forEach(([style, score]) => {
    scores[style] += score;
  });
});
```

**可能的得分范围**：
- 理论最高：8 分（8道题全选该风格）
- 理论最低：0 分（从未选该风格）
- 实际常见：1-6 分

#### 2. 判定主风格

**算法**：
```javascript
// 按得分排序
const sorted = Object.entries(scores).sort((a, b) => b[1] - a[1]);
const highest = sorted[0][1];      // 最高分
const secondHighest = sorted[1][1]; // 第二高分

// 判定规则
if (highest >= 3 && secondHighest < 2) {
  // 单一主导：最高分 ≥3 且第二高分 <2
  return sorted[0][0];  // 例如：rational
}
else if (highest >= 2 && secondHighest >= 2 && (highest - secondHighest) <= 1) {
  // 组合型：都 ≥2 且差距 ≤1
  return `${sorted[0][0]}_${sorted[1][0]}`;  // 例如：rational_avoidant
}
else if (highest >= 2) {
  // 单一主导：最高分 ≥2 但第二高分 <2
  return sorted[0][0];
}
else {
  // 平衡型：所有风格得分都 <2
  return 'balanced';
}
```

**判定示例**：

| 得分情况 | 判定结果 | 说明 |
|---------|---------|------|
| rational: 5, avoidant: 2, 其他: <1 | `rational` | 单一主导（5 ≥ 3，2 < 2×1.5） |
| rational: 3, avoidant: 2.5, 其他: <1 | `rational_avoidant` | 组合型（都 ≥2，差距 0.5 ≤1） |
| rational: 2.5, intuitive: 1, 其他: <1 | `rational` | 单一主导（2.5 ≥ 2，1 < 2） |
| 所有风格: <2 | `balanced` | 平衡型 |

### 最大化倾向（Q9-Q10）

**算法**：
```javascript
const counts = { maximizer: 0, satisficer: 0, mixed: 0 };

answers.forEach((answerIndex, questionIndex) => {
  const option = MAXIMIZER_QUESTIONS[questionIndex].options[answerIndex];
  counts[option.value] += 1;
});

// 判定（简单多数）
if (counts.maximizer > counts.satisficer) {
  return 'maximizer';
}
else if (counts.satisficer > counts.maximizer) {
  return 'satisficer';
}
else {
  return 'mixed';
}
```

**判定示例**：

| Q9 | Q10 | 结果 |
|----|-----|------|
| maximizer | maximizer | `maximizer` |
| satisficer | satisficer | `satisficer` |
| maximizer | satisficer | `mixed`（平局） |
| mixed | maximizer | `mixed`（mixed 算作平衡） |

## 设计理念

### 1. 情景化而非自评

**为什么不用"你觉得自己是理性的吗？"**
- ❌ 自评容易受社会期望影响（理性型听起来更好）
- ❌ 用户可能不了解自己真实的决策方式
- ✅ 具体情景能反映真实行为

**示例**：
- 好："周末约朋友吃饭，怎么选餐厅？"
- 差："你在做决定时会收集信息吗？"

### 2. 场景多样化

覆盖不同决策场景：
- 日常小决策（吃饭、零食）
- 消费决策（网购外套）
- 重大决策（换工作）
- 决策后反应（反思、后悔）

### 3. 允许混合得分

部分选项给多个风格各 0.5 分：
- Q4-C："其实心里有答案，但不敢行动"
  - intuitive +0.5（有内心答案）
  - avoidant +0.5（不敢行动）
- Q7-C："拿起来又放回去，纠结一会儿"
  - avoidant +0.5（回避决策）
  - rational +0.5（理性思考）
- Q8-C："决定要做，但需要时间好好想"
  - rational +0.5（需要思考）
  - intuitive +0.5（内心酝酿）

**理由**：真实决策行为往往是混合的，这样更准确。

### 4. 避免明显的"好"答案

**反例**（不好的设计）：
- ❌ A. 仔细分析后做决定（听起来正确）
- ❌ B. 冲动行动（听起来不好）

**正确设计**（当前方案）：
- ✅ 每个选项都是中性的，没有对错
- ✅ 用户根据"这更像我"来选择，而不是"这更好"

## 题目质量评估

### 优点

1. ✅ **情景化设计** - 所有题目基于真实决策场景
2. ✅ **覆盖全面** - 5种风格都有至少2个测量点
3. ✅ **快速完成** - 10道题约2-3分钟
4. ✅ **无明显正确答案** - 降低社会期望偏差
5. ✅ **允许混合** - 部分选项给多个风格加分，更准确

### 改进空间

1. ⚠️ **avoidant 过度测量** - Q2、Q4（两个选项）、Q5、Q7、Q8 都测 avoidant，而 spontaneous 只有 Q2、Q7、Q8
2. ⚠️ **组合型难触发** - 差距必须 ≤1，但 avoidant 容易高分，导致很难与其他风格形成"接近"的组合
3. ⚠️ **最大化倾向题目少** - 只有2道题，可能不够稳定

### 建议优化（可选）

**增加 spontaneous 和 intuitive 的测量**：
- 在 Q4、Q5 中增加更多 spontaneous 和 intuitive 的选项
- 减少 avoidant 的测量点

**放宽组合判定条件**：
- 将"差距 ≤1"改为"差距 ≤2"
- 这样更容易触发组合型（如 rational: 4, avoidant: 2.5）

**增加最大化倾向题目**：
- 从 2 道增加到 3-4 道，提高可靠性
